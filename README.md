# Chronicles of the Lost Dungeon

A 3D dungeon game in Unity 6. Clear 5 rooms of skeletons, find keys and escape. The real weather in Kigali changes each game.

## Install and play

**Web:** open the Unity Play link and click Play. Nothing to install.

**Windows:**
1. Download `LostDungeon-Windows.zip`.
2. Right-click it, choose **Extract All**, and open the new folder.
3. Double-click `LostDungeon.exe`.
4. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. It shows because the game is not signed.

**Android:**
1. On your phone, open the `LostDungeon.apk` link in Chrome and download it.
2. Open the file. If Android asks, allow **Install unknown apps** for Chrome, then go back.
3. Tap **Install**, then **Open**. If Play Protect warns you, tap **Install anyway**.
4. Hold the phone sideways. Drag the left side to move, tap the round buttons to fight.

## Run it in Unity

Open in Unity **6000.6.7f1**, click **Tools > Lost Dungeon > Build Game**, open `Scenes/MainMenu` and press Play.

**Controls:** WASD move, left click strike, Space dash, Q fireball, E use, Esc pause. Touch and gamepad work too.

## Code

- `Scripts/Core`: plain C# rules (health, saving, A*, pooling). No Unity, fully tested.
- `Scripts/Game`: the Unity side (player, enemies, levels, UI).
- `Editor`: tools that build the levels and the game.

Systems talk through events, so they don't know each other. A new enemy is just a new `EnemyData` asset and behaviour.

**Patterns:** Singleton (managers), Observer (`GameEvents`), Strategy (abilities, enemy AI), State (enemy states), Object Pool (projectiles, enemies, effects).

**Interfaces:** `IDamageable`, `IAbility`, `IEnemyBehaviour`, `IInteractable`, `ICollectable`, `IPoolable`, `IState`, `INavigationGrid`, `ISaveStorage`, `IDashable`.

## Addressables

Each of the 5 levels is its own Addressables bundle, with its enemies, models and effects. `LevelManager` loads a level with `InstantiateAsync` (with a loading bar) and frees it with `Release` when you leave. If loading fails, you get a message and a Back button. **Tools > Lost Dungeon > Build > Windows / WebGL / Android** builds the content for that platform, then the game.

## Weather API

[Open-Meteo](https://open-meteo.com) gives the weather in Kigali. Rain slows enemies, heat speeds them up, and night makes the dungeon darker. With no internet, the game just plays normally.

## Algorithms

- **A\* pathfinding:** lets enemies walk around obstacles. It finds the shortest path while checking few cells.
- **Min-heap:** gives A* the best cell next, faster than searching a list.
- **Nearest search:** picks the closest chest or door to open, in one simple pass.
- **Insertion sort:** keeps the inventory in order. It suits a small list.

## Saving and platforms

Progress, stats, inventory, settings and unlocks are saved as JSON. `#if` checks handle each platform: browser storage on WebGL, lighter graphics and vibration on phones, vsync on PC.
